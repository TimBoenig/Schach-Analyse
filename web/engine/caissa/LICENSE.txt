Caissa chess engine, WebAssembly build
======================================

This folder contains a build of the Caissa chess engine (version 2.0) for web
browsers. Caissa is written by Michał Witanowski and released under the MIT
license: https://github.com/Witek902/Caissa

The files caissa.js and caissa.wasm are compiled from the unmodified Caissa 2.0
sources plus the small changes in caissa-wasm.patch and the files wasm_main.cpp
and glue.js of this project. caissa.pnn is Caissa's neural network
"eval-ml-8-152B-spsa" as published with the engine
(https://github.com/Witek902/Caissa-Nets).
